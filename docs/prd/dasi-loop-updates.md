# Dasi Loop: PRD 문서 보존과 업데이트 안내

Status: awaiting_decisions — draft revision 2, 2026-10-29

## 문제와 사용자 의도

사용자는 기능 구현 요청 시 PRD 초안을 만들고, 검토 결과와 필요한 결정을 사용자와 논의한 뒤 구현하기를 원한다. 작업 도중 방향을 잃거나 대화 문맥이 사라졌을 때 PRD를 기준으로 판단할 수 있어야 한다. 또한 Dasi Loop 사용을 마쳤을 때 새 npm 버전이 있으면 업데이트 안내를 받아야 한다.

현재 0.4.0은 계획을 디스크의 실행 기록에 저장하지만 별도 PRD 파일 생성을 요구하지 않았다. 전역 CLI 0.4.0과 사용자 공용 스킬 0.3.1의 불일치도 확인됐고, 승인 후 공용 스킬을 0.4.0으로 갱신했다.

## 요구사항과 범위

- PRD-1: 신규 기능·의도된 동작 변경·기획 요청에는 프로젝트 문서 규칙에 따라 Markdown PRD를 자동으로 생성하거나 갱신한다. 규칙이 없으면 `docs/prd/<feature-name>.md`를 사용한다.
- PRD-2: 초안을 사용자에게 링크로 제시하고, 결함·미결정 사항·선택지를 논의한다. 답변과 합의 내용을 문서에 반영한다. 사용자 합의 전에는 구현을 시작하지 않는다.
- PRD-3: 문맥이 사라지거나 작업을 재개할 때 PRD와 실행 기록을 다시 읽는다. PRD와 실행 계약이 다르면 실제 사용자 합의를 기준으로 해소한다.
- PRD-4: 사용자가 기술에 익숙하지 않아도 판단할 수 있도록 누락된 요구사항과 이유, 선택지별 사용자 경험·범위에 대한 영향, 추천안과 근거를 먼저 설명한다. 일상적인 기술 선택은 에이전트가 처리하고 중요한 제품 결정을 사용자에게 묻는다. 제안·구현·실제 검증 상태를 구분해 보고한다.
- UPDATE-1: 루프 최종 결과를 기록한 뒤 npm의 최신 버전을 확인하고, 새 버전이 있으면 최종 사용자 답변에 현재·최신 버전과 업데이트 명령을 안내한다.
- UPDATE-2: 조회 실패가 작업 결과 저장이나 보고를 실패시키지 않는다. 자동 설치는 수행하지 않는다.
- UPDATE-3: 전역 npm 패키지 갱신 시 기존 사용자 범위 Codex/Claude 스킬을 백업 후 동기화한다. npm 11+의 설치 스크립트 허용 조건과 수동 대안을 설명한다. 프로젝트 설치본은 명시적으로 갱신한다.

## 사용자 흐름

기능 요청 → PRD 초안 생성 → 독립 기획 검토 → 사용자에게 문서·질문 제시 → 답변에 따라 수정 → 사용자 합의 → 구현 → 독립 평가·점수·개선 → 최종 보고와 버전 안내.

기획 검토는 구현 점수를 부여하지 않는다. 구현 점수는 합의된 기준을 고정한 뒤 각 구현 라운드에서 계산한다.

## 완료 기준

- AC-1: 기능 계획이 읽을 수 있는 PRD 파일로 남고, 초안·미결정·합의 상태를 구분한다.
- AC-2: 사용자 질문·답변·결정·완료 기준이 문서와 실행 계약에 일치한다. 재개 시 이 문서를 기준으로 판단한다.
- AC-3: 루프 종료 시 새 버전이 확인되면 사용자가 최종 답변에서 알림을 받는다. 사용자/프로젝트 설치 범위에 맞는 업데이트 방법을 제시한다.
- AC-4: 버전 조회 실패나 잘못된 응답은 완료 기록을 손상시키거나 거짓 업데이트 알림을 만들지 않는다.
- AC-5: npm 갱신과 복사된 스킬의 갱신 관계, 스크립트 허용 조건, 백업, 프로젝트 갱신 경로를 설명한다.
- AC-6: 제품 결정 질문에는 이해 가능한 설명과 추천 근거가 동반된다. 추천안과 사용자 결정은 구분해 기록한다.

## 결정과 미결정 사항

- 확인된 사용자 요구: PRD를 실제 문서로 남겨 이후 판단 기준으로 사용한다. 사용자의 이번 지적을 근거로 요구사항에 반영했다.
- 확인된 사용자 요구: 새 버전 알림을 포함하기 전에 후속 npm 버전을 먼저 배포하지 않는다.
- 확인된 사용자 요구: 사용자는 “내가 잘 모르니 네가 가르쳐줘도 돼”라고 했고, 설명·선택지·추천 근거를 제공하는 방식에 “그게 필요할 거 같아”라고 동의했다. PRD-4에 반영하며, 다른 미결정 사항이나 전체 PRD의 승인으로 해석하지 않는다.
- 미결정: 설치 버전 메타데이터가 없는 구버전에 일반적인 “설치 버전 미상” 안내를 표시할지 여부. 추천은 정확한 버전을 추정하지 않고 최신 npm 버전과 갱신 방법을 안내하는 것이다. 아직 사용자 선택으로 기록하지 않는다.
- 이 문서 전체의 최종 합의와 구현 점수 기준은 아직 확정하지 않았다.

## 진행 상태와 증거

- PRD 자동 작성·사용자 질문·문맥 복구 지침을 스킬 소스에 추가했다. 새 세션에서 실제 동작 검증은 아직 하지 않았다.
- 사용자 공용 스킬은 기존 공개 버전 0.4.0으로 갱신돼 있다. 이번 소스 수정은 아직 공용 스킬에 설치되지 않았다.
- 사용자 범위 postinstall 동기화 초안과 로컬 패키지 0.5.0 준비 변경이 있다. CLI 문법 검사와 npm pack dry-run은 통과했다.
- 새 버전 알림 코드는 아직 구현하지 않았다. 0.5.0은 배포하지 않았다.
